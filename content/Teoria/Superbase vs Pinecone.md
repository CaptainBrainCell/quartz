***Scalability*** 
-> *Superbase* : najlepsie pre mensie alebo medium velke vektorove databazy
-> *Pinecone* : lepsie (optimalizovane) pre vacsie vektorove databazy (biliony vektorov)

***Hosting***
-> *Superbase* : mozeme si ju self hostnut 
-> Pinecone : nie je mozne si self hostnut, funguje ako SaaS

***Kam sa hodi?***
-> *Superbase* : do takych hybridnejsich pripadov, kedy miesame metadata, vektor search a relational data
	-> *Pinecone* : idealne pre aplikacie, ktore potrebuju cistu vector search
